# Dark Browser

Десктопный браузер Dark.Tehno на **TypeScript + Electron** (Chromium) с привязкой к аккаунту **Dark.Account**.
Интерфейс собран по «Стандарту оформления веб-страниц Dark.Tehno» (редакция 1.0): те же токены, шрифты и компоненты.

## Запуск

```bash
npm install
npm start          # сборка + запуск
npm run dev        # то же + DevTools интерфейса
npm run typecheck  # проверка типов
npm run dist       # установщик (NSIS / AppImage+deb / dmg) через electron-builder
```

Нужен Node.js 20+.

## Привязка к аккаунту

Нажмите «Войти» в правом верхнем углу: вход, регистрация и подтверждение 2FA по коду из письма. Секретный ключ приложения не требуется.

Что даёт привязка:
- браузер регистрируется как **устройство** аккаунта (`windows|linux|macos` + версия в заголовке) и виден в разделе «Устройства» на сайте;
- токен устройства хранится в `safeStorage` ОС (Credential Manager / Keychain / libsecret); если хранилища нет, токен живёт только в памяти;
- при запуске сессия проверяется запросом `GET /profile/`; при 401 токен сбрасывается;
- в кабинете браузера (`dark://account`): профиль и аватар, 2FA, устройства (переименовать, доверять, удалить), история входов, «Отвязать браузер» (`POST /auth/logout/`).

Синхронизации закладок и истории через аккаунт нет: в Account API для этого нет маршрутов. Данные хранятся локально.

## Загрузки, прокси и родительский контроль

- История загрузок доступна через `dark://downloads` или `Ctrl+J`: показывает ход и статус загрузки, позволяет открыть файл, найти его в папке и удалить запись. Файлы сохраняются в системную папку загрузок.
- Прокси задаётся в настройках (`http`, `https`, `socks4` или `socks5`). Учётные данные прокси шифруются системным `safeStorage`; пароль не возвращается в интерфейс.
- Родительский контроль включает отдельные профили для сайтов для взрослых ([`porn-only`](https://raw.githubusercontent.com/StevenBlack/hosts/master/alternates/porn-only/hosts)) и известных рекламных/вредоносных доменов ([базовый список](https://raw.githubusercontent.com/StevenBlack/hosts/master/hosts)) проекта [StevenBlack/hosts](https://github.com/StevenBlack/hosts), а также собственный список доменов. Списки загружаются вручную по HTTPS, проверяются перед заменой и блокируют домены и поддомены. PIN длиной 4–12 цифр хранится в виде хеша `scrypt`; PIN требуется для изменения настроек и прокси, редактирования списка сайтов и отключения контроля. После пяти неверных попыток ввод блокируется на минуту.
- Фильтры работают по доменам, не анализируют содержимое страниц и не гарантируют обнаружение всех нежелательных или мошеннических сайтов. Перед включением учитывайте возможные ложные срабатывания и регулярно обновляйте списки вручную.
- Все данные и настройки хранятся локально на этом компьютере.

## Структура

```
src/main/      основной процесс: окно, вкладки (WebContentsView), протокол dark://, IPC, клиент Account API
src/preload/   chrome.ts — для интерфейса; page.ts — API только для страниц dark://
src/chrome/    полоса вкладок, адресная строка, чип аккаунта
src/pages/     dark://home, account, settings, bookmarks, history, downloads, blocked, error
src/static/    theme.css — токены и компоненты стандарта
src/shared/    омнибокс-резолвер, общие типы
```

## Безопасность

- Сайты работают в sandbox с `contextIsolation`, без Node; API получают только страницы `dark://`, адрес отправителя проверяется в каждом IPC-обработчике.
- Адресная строка не открывает `javascript:`, `file:`, `data:` — такой ввод уходит в поиск.
- Прокси-учётные данные шифруются средствами ОС, а PIN родительского контроля не сохраняется в открытом виде.
- Камера, микрофон, геолокация и уведомления — только после явного вопроса в оформленном окне браузера; уведомления сайтов отображаются как стилизованные сообщения поверх страницы.
- Запросы к API идут с `redirect: 'error'`, чтобы токен не уходил по чужому редиректу.

## Отклонения от стандарта (допустимые для десктопа)

- Вместо одной верхней панели 64 px — две строки: вкладки 40 px + навигация 48 px; тема и цвета те же.
- Общие стили вынесены в `theme.css` (рекомендация п. 11.1 для групп страниц), а не в `<style>` каждой страницы.
- Скрипты страниц — обычные IIFE без библиотек; язык интерфейса русский.
- Шрифты подключаются с Google Fonts; без интернета используются системные запасные.
